## 几何和贴图分工

**格框：** 合并的边条网格提供有厚度的线框与面分割，一次绘制；核心很小，避免一个大光球遮住格子。碎块用MultiMesh实例化，数量增多不按数量增加绘制调用。

**脉冲环：** 连续的平面环带，环平面垂直局部Z轴；不是将圆柱首尾拼接。暖色主体是UV受控的开口圆冠，后缘有不规则撕裂。当前默认周期0.45秒是依据可见动态作出的可调校准值，不代表恢复了原作者参数。

设 `p = fposmod(effect_time + ring_index * period / 3, period) / period`：

- 环位置 `z = -0.03 + 1.72*p`，朝后方传播。
- 环尺度 `0.40 + 0.92*p`，逐渐放大。
- 环透明度 `sin(PI*p)*0.65`，避免在循环边界突然出现或消失。
- 三环分别保存材质与相位，实例之间也独立。

**冠壳：** 网格前67%纵向区间生成圆润鼻端，后33%生成外扩的开口后缘。末端用环向波形形成不等长尖齿；另加一圈有缺口的宽亮边和两片较大的不对称薄片。外壳没有封闭后盖，也没有绕球体的“原子轨道”。

贴图仍复用工程已有灰度数据，不引入逐帧图动画：

|---|---|
|`T_Noise1_tiled.png`|双频流动噪声，决定破口、亮暗斑块与消融。读取红通道，按线性数据采样|

## Shader的具体逻辑

`energy_surface.gdshader`中当前主要分支：

- `layer=2`：格框扫描高亮与轻微噪声变化；主色是黄绿，内部碎块是青绿。
- `layer=3`：小核心的深浅色与边缘响应，独立于外壳。
- `layer=5`：冠壳。U绕轴一周，V从鼻端走向后缘；噪声与Voronoi共同挖空，Fresnel与前端/后缘权重产生青白亮区。后缘有小幅顶点起伏。
- `layer=6`：脉冲薄环。解析横向柔边，保持完整轮廓；出生/死亡透明度由脚本的周期包络控制，避免噪声把薄环切成碎点。
- `layer=7`：暖色破损圆冠。暖色与热点色混合，噪声切出较大的缺口，尾端渐隐。
- `layer=8`：轴向能量线。深色内部与亮边分开，末端衰减；顶点随可重置的效果时间抖动。橙色抖动幅度较小，蓝色较大。

所有时间都来自本实例累计的delta并传给 `effect_time`，而非不可重置的全局TIME。半透明层加色、禁写深度并保留深度测试。材质输出ALBEDO与EMISSION，经Forward+截图确认；不能以无头编译成功代替实际显示检查。

`energy_sprite.gdshader`只负责柔光和命中短闪；`energy_fragments.gdshader`读取MultiMesh实例颜色与透明度，避免白色Emission冲掉碎块原有颜色。

## 命中与复用

方块命中改成扩张的平面方形框，避免把飞行立方体直接放大。其余命中仍保留独立的短闪、扩张环和碎片散射。时间包络为设计重建；4.34秒片段无法给出所有效果无遮挡的完整生命周期。

`reset_effect()`清空时间、世界位置历史和消融，并恢复可见；`seek_preview(seconds)`用于同相位截图。世界历史约60Hz采样，实例之间材质独立、几何共享。新增回归验证了脉冲环的错相、后向传播和尺度增长，并继续验证跨地点对象池复用。

可调参数包括 `radius`、`rotation_speed`、`density`、`emission_energy`、`trail_length`、`pulse_period`。`dynamic_light`决定初始化时是否创建小范围无阴影灯光。

## 验证与边界

Headless / Forward+ reference-projectiles通过；Forward+关键帧和72帧序列渲染无错误。对象池复用、材质隔离、世界尾迹重置通过。Headless沿用现有引擎采样器诊断过滤。

本轮按可见轮廓和动态进一步对齐，不宣称恢复原作者Shader源码或逐像素一致。尤其是具体噪声图、随机种子、原始曝光和环的原始参数无法从视频唯一反推。正式战场混战表现仍需独立评估，实验室的RTS观察角度不能替代它。

复查：`./tests/run_game_checks.ps1 -Renderer forward -Scenario reference-review`；生命周期：`-Scenario reference-projectiles`。动态捕获使用 `tests/reference_projectiles_review.gd -- --sequence`，基准使用同脚本的 `--benchmark`。
