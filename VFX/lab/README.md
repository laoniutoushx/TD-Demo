# VFX 实验室

打开 [VFXLab.tscn](VFXLab.tscn)，按 **F6**。默认展示绿色方块飞行效果，原地播放、静音。

## 界面怎么用

- **左侧特效库**：搜索名称或资源路径；按飞行、命中、状态、技能、建造、升级、掉落、贴花、治疗或占位筛选。点击特效即切换；“查看配套命中/飞行”用于存在同名配套资源的成对切换。
- **顶部播放栏**：重播、暂停/继续、停止、循环、0.25/0.5/1/2倍速、静音、截图和隐藏面板。
- **中间预览**：拥有独立3D世界，菜单不会遮挡画面。近景、侧视和RTS观察角度可快速切换；自动取景考虑预览区宽高比。
- **右侧「效果」**：尺度、发光强度、色彩叠加、原地/直线/弧线、重播周期，以及可用的专属参数和图层开关。
- **右侧「舞台」**：中性深灰、浅灰、纯黑、草地色四种衬底；地板和背景可以独立调色。柔和的1米网格、地板和Bloom均可关闭。

默认地板显式使用哑光材质，网格向远处淡出。草地色仅用于衬色观察，不是正式关卡。色彩叠加是乘色：白色保留原有配色，不会将所有复杂Shader直接替换成一种颜色。

## 鼠标和快捷键

|操作|用途|
|---|---|
|右键拖动预览区|旋转机位|
|中键拖动|平移观察点|
|滚轮|缩放|
|F|重新聚焦，恢复自动取景|
|空格|暂停/继续|
|R|重播|
|Tab|显示/隐藏两侧面板|

编辑文字或数值时，快捷键让位于输入操作。手动调整镜头后保留自己的构图；重新聚焦或切换机位可恢复自动取景。窗口缩放时自动取景会重新适配。

## 预设和 A/B

左下角始终可见“记录A”“交换A/B”“加载预设”和“另存预设”。先记录A，再调当前版本B，点击交换比较。交换和加载后所有参数及舞台控件都会回填，保留同一机位便于比较。

保存使用文件对话框，可命名新的 `.tres`；不自动覆盖正式特效资源。预设包含稳定资源路径、兼容旧版的索引、外观、运动方式、专属参数、地板/背景与舞台显示设置。旧版预设仍可加载，包括省略默认索引0的预设。

暂停会冻结当前效果时间，仍可操作菜单与镜头。图层显示设置在循环重播后保留。实验室退出后恢复原有全局时间倍率和窗口缩放配置。

## 截图与反馈

顶部“截图”默认导出**纯预览区域**，不会把菜单拍进去；同时保存 `.tres`参数和 `.json`环境报告。输出为 `.godot/vfx_lab/capture_*.png`。底栏显示结果，点击“复制输出路径”获取完整文件路径。

你可以把截图和想改的部分发给我；需要分析节奏时提供短录屏更合适。三款参考特效的拆解见 [制作拆解](../projectiles/reference_set/制作拆解.md)。

## 全量资源目录

当前自动收录 `res://VFX` 下61个场景（含变体），排除实验室自身和被`.gdignore`排除的目录。纹理、材质和Shader是场景依赖，不会单独作为可播放项目列出。两个原始空场景（能量护盾、默认弹命中）归为“占位”，舞台标题与底栏会明确说明；流血保留为原始粒子样例，不自动改造原资源。

新增`.tscn`或`.scn`后点击搜索框旁的“刷新”即可重新发现。目录按完整路径区分资源，避免同名变体相互覆盖。最早12项的旧索引保留兼容；新预设和A/B按资源路径定位，目录插入新项不会导致错配。

预览适配包含：

- 动画自动选择已有的run/running/burning/default片段；一次性脚本自行销毁后仍按预览周期重播。
- 激光使用原场景的set_line接口生成独立线段，暂停战斗单位跟随逻辑，不创建战斗单位。
- VFXInstance触发play，关闭预览实例的自动池回收和战场相机震动，清理由实验室管理。
- 用独立挂点控制尺度和运动，保留原场景自带缩放及动画。
- 建造、贴花、地面法阵按落地高度摆放；贴花可配合浅灰衬底和RTS观察角度。
- 优先按主体网格/贴花取景；纯粒子按发射与运动参数及建议范围估算，不读取尚未初始化的GPU缓冲。手动滚轮可继续调整。

全量截图检查：`./tests/run_game_checks.ps1 -Renderer forward -Scenario vfx-catalog`。清单与缩略图见 [资源清单](../../docs/vfx_lab/catalog/manifest.json)、[预览1](../../docs/vfx_lab/catalog/contact_1.png)、[预览2](../../docs/vfx_lab/catalog/contact_2.png)、[预览3](../../docs/vfx_lab/catalog/contact_3.png)。存量使用全局TIME的Shader保留其原有时间逻辑，不承诺重播时恢复完全相同的随机画面。


## 按特效生成的专属参数

选择资源后，“效果 → 专属参数”会按当前实例重新生成，不再使用固定的六项属性名单。

- 脚本效果：读取公开的 `@export` 数值、布尔、颜色、Vector2/Vector3 和枚举；资源引用与内部运行状态不作为艺术参数显示。
- 无控制器接管的 Shader：显示可编辑的数值、颜色和向量 Uniform；排除时钟、形成度和内部光照输入。相同材质只显示一次。
- 普通 GPU 粒子：显示数量、寿命、模拟速度；ParticleProcessMaterial 额外显示初速、尺寸与重力。参数按具体粒子节点区分。
- 修改只作用于预览实例；保存预设、A/B 和重播均保留属性值，切换新特效会恢复新资源自身的默认值。效果自身的 duration 与预览重播周期使用不同键，避免互相覆盖。

旋转与流动已拆开：龙卷风的“旋转速度”改变几何风带绕轴运动，“气流 / 纹理流动速度”改变风纹的流动；二者默认均为 1，不改变已保留白风的默认外观。还可调整风带透明度、能量亮度、碎石尺度和悬尘浓度。灰色体积款可编辑自己的高度、半径、密度与采样步数。

参数悬停提示注明“即时生效”或“修改后重建预览”；生成几何所需的属性会在进入场景树之前恢复并重建，不会只修改字段却保持旧网格。

### 为新控制器声明参数

直接 `@export_range` 即可提供范围；无需改 VFX Lab。可增加下列方法覆盖显示名称并声明该参数能否实时应用：

```gdscript
@export_range(0.0, 8.0) var flow_speed: float = 1.0

func get_vfx_parameter_schema() -> Dictionary:
    return {"flow_speed": {"label": "纹理流动速度", "live": true}}
```

未声明即时行为的普通脚本属性默认重建预览；旧的旋转、拖尾、碎片和体积参数保留原来的即时行为。带 `seek_preview` 的控制器通过导出的 API 调参，面板不直接改写它每帧管理的内部 Uniform。改变原始素材或保存正式默认参数仍需在资源中编辑；“保存预设”不会覆盖 `.tscn`。

专属定向检查：`./tests/run_game_checks.ps1 -Renderer forward -Scenario vfx-parameters`。仅覆盖白风、体积款及代表性的 Shader/粒子参数编辑、预设、A/B、重播和源资源隔离，不遍历全库。
