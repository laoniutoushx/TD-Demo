# 写实体积龙卷风

两款正式资源已直接替换：`vfx_tornado_running.tscn`（大型移动技能）和 `../funnel_tornado/vfx_funnel_tornado_running.tscn`（附着单位的小型旋风）。在 `VFX/lab/VFXLab.tscn` 运行后搜索“龙卷风”即可查看。

## 构成

- **烟尘体积**：封闭盒体只承载射线入口/出口；真正的漏斗是 shader 内的三维密度场，不是发光锥面或交叉面片。96³ seamless NoiseTexture3D 使用固定种子的四层 FastNoiseLite，所有实例共用噪声数据，材质和时间独立。
- **形态与运动**：窄底宽顶、非对称摆轴、顶端渐散；粗细两层旋转噪声叠加，不同高度差速，气流纹理向上推进。碎屑沿螺旋上升，末端缩小消失。
- **光照**：Beer–Lambert 透射累积，沿主光方向追加两次密度采样近似内部遮光；烟尘由灰色渐变到贴地褐色。获取相同 World3D 的主方向光，每 0.25 秒更新方向、颜色、能量，同时读取环境光能量。不会抓到另一个预览世界的灯。
- **接地**：40 个低透明烟尘粒子，使用现有 smoke_04.png；世界坐标模拟，在移动中留下短暂尘土尾迹。径向渐变 Decal 近似接触遮光。
- **细节**：64 个 MultiMesh 小碎屑，共享低面数网格；无额外逐碎屑节点。保留原有音源，音量从过高的 +30 dB 调整为 -12 dB。
- **遮挡**：关闭代理盒自身的硬件深度测试，使用场景深度截断积分；不穿过地板和不透明单位。支持透视、正交、相机进入体积内部。透明物体之间的排序仍受引擎透明渲染规则限制。

这是一种实时体积近似，不是流体解算；没有天气云底、真实流体与环境物件的物理交互，也没有向整个场景投射精确体积阴影。贴地阴影由 Decal 近似。

## 调整

实验场专属参数支持自转速度、烟尘厚度、体积采样步数，支持预设、A/B、暂停、重播。改动只作用于预览实例；正式默认值在场景或脚本 Inspector 中修改。

| 参数 | 默认/建议 | 用途 |
| --- | --- | --- |
| rotation_speed | 1.0 | 旋转速度；0 停止角向旋转，仍有向上气流 |
| optical_density | 大型 3.8 / 小型 5.6（补偿较短的光线路径） | 厚度及自遮光；过高会糊成实心 |
| volume_steps | 56，范围 24–72 | 游戏可尝试 32–40，近景检查 56–72 |
| funnel_height / funnel_radius | 大型 9.5/2.65；小型 4.2/1.2 | 在实例进入场景树之前设置；生成代理几何与粒子范围 |

shader 的 smoke_color、dust_color 是 source_color，可在代码设置并通过实验场整体色彩叠加。`reset_effect()` 重置形成时间和粒子；`seek_preview(t)` 精确定位体积和碎屑时间，地面 GPU 粒子仍按引擎独立模拟，因此它不是完整的粒子离线求值器。

## 玩法与资源兼容

保持两个正式 .tscn 的路径与 UID。大型保留 `Area3D/CollisionShape3D`、layer=0、mask=2、圆柱高 10、半径 4、局部 y=4.21184。形成动画只改变密度与碎屑显示，不缩放根节点、不移动相机或修改技能飞行、伤害、持续时间。对象池重用调用 reset_effect；取消旧的根节点缩放动画，防止命中区域随出现动画变化。

## 验证与预览

- Forward+ `tornado-review`：两款加载、原碰撞接口、根变换、重置、截图、正交/内部视角、GPU 时间采样。
- Forward+ `skill-vfx-buff`：技能兼容回归。
- Forward+ `vfx-lab`：61 款全库预览、龙卷风参数 A/B、暂停、重播与取景。
- headless `full`：完整游戏流程回归。

运行：`./tests/run_game_checks.ps1 -Renderer forward -Scenario tornado-review`。

输出在 `.godot/tornado_review/`；交付图和动态短片在 `docs/vfx_tornado/`。短片为固定时间步的实机画面序列，不是性能录像。

RTX 3060 / Forward+ / 1280×800 / 56 步，在固定测试镜头中，每项采样 60 帧，GPU 视口耗时中位数：空场 0.33 ms、单个 0.97 ms、三个 5.05 ms（含场景基础渲染）。这些是该镜头下的测量，近景覆盖率、重叠、硬件及其他负载都会改变结果；保留原始 timings.json 供复查。
