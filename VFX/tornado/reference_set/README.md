# 视频参考龙卷风套件

参考：`S:/PixPin_2026-11-14_20-27-26.mp4`。本套件独立新增 11 款视频风格及 1 款青绿风系，没有替换正式技能使用的灰色体积龙卷风。

## 直接查看

在 Godot 运行 `res://tests/TornadoReferencePreview.tscn`。左右键切换 12 款、Space 暂停、R 重播，右键拖动旋转、滚轮缩放。此场景只加载本套件，不依赖 VFX Lab 或游戏场景。

交付总览和带款式标签的 24 秒动态短片：`docs/vfx_tornado_reference/contact.png`、`showcase.mp4`。每款同时保留单独的 MP4、形成期、正常透视、浅色背景和 RTS 俯视 PNG。

## 结构与实际差异

共享几何包含两层连续漏斗、三条宽幅螺旋带、破碎扩口和两条贴地旋流。几何带有高度相关的起伏与非对称横截面；shader 以低频无缝噪声切割宽窄，再叠加螺旋流向细节，避免原来的空心细线圈。

`flow_noise.tres` 使用固定种子的 FastNoiseLite 生成 512² 无缝密度纹理；不需要外部素材下载。两次噪声采样产生粗细扰动，流向纹理与上升相位分别变化。透明风带、深色烟芯、亮边能量并非统一加色混合。无光照材质的 HDR 颜色直接写入 ALBEDO，保证火焰与电弧在当前渲染器中实际可见；Bloom 用于散射光晕，不承担轮廓。

| 样式 | 专属处理 |
| --- | --- |
| wind | 青白通透内层、破碎白边、淡色贴地雾 |
| dark_red | 暗黑烟芯、红色裂片、局部红光 |
| chaos | 黑白灰分层，低发光，碎片轮廓 |
| violet / blue | 暗色核心、不同能量亮边，较短而紧凑 |
| debris | 灰白薄雾、较多实体石块、低密度体积烟尘 |
| electric | 4 组分叉电弧、顶部脉冲电光；电弧形态以 11 Hz 更新，连续气流独立运动 |
| sand | 40 步三维射线步进烟柱、褐色吸收和自遮光、地面及顶部悬尘、石块 |
| fire | 独立双层火焰噪声与热度渐变、11 片上下火舌、90 个火星、烟雾、地面暖光 |
| wild_blue | 更宽扩口、更多螺旋圈数、蓝白流带 |
| anime | 硬阈值切片、白色与灰色块、实体碎石，不使用火焰式光晕 |
| green | 独立青绿风系资源，保持通透风带及淡绿亮边 |

共享控制器中的 `SHAPES` 明确配置各款高度、半径、圈数和内层透明度；`COLORS` / `HIGHLIGHTS` / `ENERGY` 配置色彩与亮度。Inspector 提供样式枚举和旋转速度。修改正式效果请改其资源或配置；独立预览不写回场景。

## 接入与生命周期

独立资源命名为 `vfx_tornado_<style>_running.tscn`，可通过 `create_vfx("tornado_fire", "running")` 等现有工厂调用。12 个资源名唯一，旧 `tornado` 与 `funnel_tornado` 路径及 UID 不变；新款不附带伤害碰撞、相机震动或自动结束逻辑，由调用方控制持续时间。

- `play()`：显示、清零形成时间并恢复更新。
- `stop()`：隐藏并停止更新，不销毁对象。
- `reset_effect()`：清零形成时间，重置碎屑、尘雾及电弧状态。
- `seek_preview(seconds)`：确定性定位主体、石块、光屑、尘雾、光照和电弧。暂停时停止根脚本处理即可，不修改全局 Engine.time_scale。

所有动态粒子使用 MultiMesh 和解析轨迹，避免 GPU 粒子在重播或定位后状态不一致。实例只共享只读几何与纹理，ShaderMaterial 与时间各自独立。体积光照为近似；没有流体物理求解，也不向整个场景投射精确体积阴影。

## 仅本套件的验证

`./tests/run_game_checks.ps1 -Renderer forward -Scenario tornado-reference`

检查 12 款的正式工厂创建、材质隔离、独立时钟、确定性石块/尘雾、stop/play、对象池身份与状态重置、根变换，以及形成期、透视、浅色背景和正交画面。输出 `.godot/tornado_reference_review/report.json` 包含 1280×800 Forward+ GPU 视口计时样本；它包含舞台和后处理开销，受系统负载影响，不代表单独特效的净耗时或游戏帧率。

录制：Godot 运行 `--script tests/tornado_reference_review.gd -- --capture`，再执行 `python tests/export_tornado_reference.py`。每款短片是 24 fps 固定时间步的原生渲染序列，不是性能录像。支持 `--only=electric` 定向重录一款。

本轮没有运行 VFX Lab、全库特效或全游戏回归。实验场只补充新款名称元数据，由其既有目录发现机制显示资源。

视频中缺少近景的款式按可见轮廓与材质重建；整体仍是自建实时风带方案，并非原作者源工程或逐像素复制。


## VFX Lab 专属参数

白风资源 `vfx_tornado_wind_running.tscn` 与旧技能使用的灰色资源均保留。实验场现在自动读取导出属性，支持分别调整旋转速度、气流流速、透明度、能量亮度、碎石尺度和悬尘浓度。风带旋转与纹理流动各自独立；默认参数维持当前外观。预设、A/B、暂停编辑和重播均支持这些属性。样式枚举会重建预览实例，不覆盖白风文件。
