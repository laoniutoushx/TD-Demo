# 第十四轮：全面细节复核与 90% 目标验收

**结论：主要元素宽高误差已控制在 10% 内；整体视觉 90% 一致性仍不予通过。** 尺寸接近和交互正常不能替代材质、装饰形态的视觉验收。

## 本轮实际修复

1. 顶栏与底栏共用石面移除重复菱形花纹，复用项目已有细颗粒暗石材。Atlas 采样按 Godot 实际导入尺寸 512 像素设置，避免按原始文件尺寸取样越界。
2. 单位槽由 46×46 调为 54×54，图标由 42×42 调为 50×50；底栏外容器高度由 206 调为 214，可见石框为 874×207，更接近等比缩放参考的 874×206.3。技能和装备操作区保持现有尺寸。
3. 贪婪天赋真实冷却遮罩使用图标自身的透明轮廓，并同步显示缩放，消除透明图标背后的方形黑扇区。
4. 高度断言从含留白的外容器改为直接验证可见石框与参考高度差，允许 8 像素偏差；这是参考约束，不是整体相似度评分。

## 尺寸核对

[完整测量表](geometry_audit.md) / [机器可读数据](geometry_audit.json)。10 项宽高均落在参考 ±10% 内，底栏高度误差约 0.4%，技能槽约 1.0%，Wave 宽高约 0.4% / 1.9%。

参考尺寸为概念图人工标注，手绘边缘有约 1–3 个源像素的不确定性。它不衡量位置、纹理、颜色、叶片、字体，也不输出平均视觉分数。不得把“10 项尺寸检查通过”写成“整体视觉达到 90%”。

## 距离整体 90% 目标的剩余工作

优先处理左侧下垂叶片、顶部连接细藤及底部局部叶簇，其次统一铜角和槽框的局部磨损、薄边及内凹阴影，最后对齐主菜单/设置按钮的圆角与铜边层次。达到目标前，本验收保持“视觉未通过”，不以功能测试或尺寸误差替代艺术品质判断。
