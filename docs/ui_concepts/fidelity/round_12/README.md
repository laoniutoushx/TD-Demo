# 第十二轮：槽位边线与次级容器修复

本轮基于工作区第十一轮布局继续修复，保留底栏 874×206、技能槽 64×64、装备槽 90×90 的实际布局。对照图按统一比例呈现参考 / 第十一轮 / 当前原生截图；不输出未经验证的视觉相似度分数。

## 修复内容

- **槽位直边缺失**：原纹理外侧约 2 像素为暗色、半透明边缘，明亮边线进入图标覆盖区。新增原生 AtlasTexture 裁去外围留白，保留 2 像素内容边距，使技能、单位、装备和 Buff 槽四边重新可见。
- **转角与线宽**：固定尺寸方槽取消固定九宫格角区，按整个裁切框均匀缩放，避免角区占比过大；普通态统一为克制的橄榄铜色，悬停保留绿色区分。
- **次级容器质感**：技能、装备分区复用已有磨损石材边框，替换平滑、发亮的分区框；保留现有内容间距，调整边框采样区与色调。
- **空装备槽**：降低苔藓底图亮度，减轻纹理对图标和边线的干扰。
- **对照取样**：直接记录实际面板矩形，修正此前按固定 6 像素推算底部留白的方式；当前实际底部留白为 4 像素。

本轮复用已有位图，通过原生资源和样式调整完成，没有重新生成素材。

## 验证

原生 Forward+：1080×768、1920×1080、2560×1080 均输出 UI_MATERIAL_VIEW_OK，最终 UI_MATERIAL_REVIEW_OK；覆盖页面、选择状态、Tooltip、单位属性响应和槽位状态。

新增渲染像素回归：技能和装备槽四条直边中央的外侧两像素，至少一个像素平均 RGB 必须大于 0.20，防止边线再次被图标遮住。此检查验证边线可见性，不代表材质达到参考品质。

三轮原生游戏流程：FLOW_CYCLE_OK: 1..3、FLOW_TEST_OK，孤立节点为 0。保留既有 Fox_Mega.tres 无效 UID 回退到文本路径的警告。
