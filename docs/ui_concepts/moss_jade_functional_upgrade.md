# 苔石幽绿：功能对齐概念稿

以用户提供的 fused_ui_concept_board_1794737296784.jpg 为视觉基准，使用内置 imagegen 生成 moss_jade_functional_upgrade.png。此为设计示意，没有修改游戏界面代码。

## 已有能力

- 主菜单：开始游戏、设置、退出。
- 战斗：波次编号、金币、木材、多选单位、技能、装备、Buff、玩家天赋槽。
- 技能快捷键目前仅绑定 Q/W/E/R/T，不添加其他键位。
- 设置：背景音乐、游戏音效、画质；语言控件存在但禁用。
- 天赋选择：GREEDY、COOLDOWN、SHUTDOWN；最终文案与效果以现有资源为准。

## 概念稿调整

- 移除未经实现的暂停、倍速按钮与连续波次进度条。
- 为多选缩略图保留独立行；上方新增选中单位属性摘要。属性摘要需要绑定现有数据，当前并非已实现界面。
- 保持左技能、中装备及 Buff、右玩家天赋的功能顺序。
- 语言显示禁用与暂未开放；画质与声音保持可操作。
- 设置保留应用保存、返回取消的现有语义。

## 实装约束

- 图中数值、选中状态、冷却时间和缩略图数量均为示例，不是实际系统容量或实时截图。
- 多选容量沿用现有逻辑，不能将示意的七张卡实现为七单位上限；缩略图必须使用对应单位画像，不能直接用技能图标替代。
- 美术生成稿中的侧栏说明和额外标题不作为游戏文案；游戏名称沿用“丛林塔防”。
- 冷却、层数、等级、禁用与选中反馈只能由真实运行状态驱动，不能作为固定装饰。
- Buff 的有限持续时间显示剩余进度，常驻状态不伪造倒计时；不凭图稿新增固定武器槽限制。
- 当前程序可支持的能力不等于所有控件已经接线；新增属性展示和状态样式需要后续实装与验证。
- 主体采用深色平整底，石材与苔藓仅用于边框，玉绿用于交互状态。避免持续发光和厚边框抢占战场。
- 以当前 1080×768 检查实际字号、槽位与战场遮挡，再适配宽屏；不能按概念板缩略图直接确定控件尺寸。
